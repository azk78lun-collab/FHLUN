# Lun 分布式服务器集群（API v3）

此目录由 `lun.sh` 的“分布式服务器集群”菜单管理。模块默认不安装；启用后每台 VPS 运行同一份 `lun_cluster.py`，每个成员保有自己的身份私钥和 mTLS 证书。不存在控制器/受管角色，也不共享或迁移 CA 私钥。

## 安全与一致性

- 每个成员签名自己的事件链；事件包含作者序号、前序哈希与逻辑顺序，重复、篡改和过期重放会被拒绝。
- 成员之间仅接受结构化动作白名单，绝不接收任意 Shell 文本。
- 一次性 `lunjoin://` 加入地址只能使用一次，15 分钟后失效。加入后任意可信成员都可管理其它成员。Shell 只把后端 `nodes` JSON 明确标记为 `trusted=true` 的记录作为远控、CDN 同步和自动更新目标；旧记录的角色或状态文字不能替代信任证明。
- 联邦状态按需同步：启动、手动同步、协议重建后的快照发布和订阅缺失补齐都会触发同步；没有固定心跳。订阅 GET 由 `lun-agent` 先返回最近可信聚合文件，再异步调用 `subscription-access`；同一 Token 30 秒防抖，网络同步不得阻塞 HTTP 响应。
- 服务启动、立即同步和状态修复会通过固定 HTTPS 探测源交叉确认本机公网 IP。仅当至少两个结果一致且 IP 确实变化时，才由节点本人签名 `node.metadata` 并以 `1→10→100` 两层有界方式广播。未变化时不产生事件也不联系成员。
- Python 3.14 环境继续接受旧版 Lun 生成的无 `keyUsage` 根证书，但仅在联邦专用 TLS 上关闭该严格扩展检查；CA 链、mTLS 身份、指纹与事件签名验证仍然必须通过。
- 失败探测先在 60 秒内重试 3 次，再由其它成员复核；票数不足只标记疑似离线。撤销会留下最小墓碑，阻止旧身份复活和历史事件重放。

## 生命周期

首次在任意 VPS 选择“一键开启本机联邦身份”，Lun 自动分配 TCP 通信端口并放行本机防火墙。普通 VPS 使用空闲高位端口；NAT VPS 必须已有“公网端口-内网端口”映射。任意成员生成加入地址，另一台启用联邦身份的 VPS 粘贴地址即可加入全网。

旧式 API v2 集群可在首次进入时安全迁移。迁移只转换本机状态，保留编号、用户、Token 与订阅快照；不会复制旧共享 CA 私钥，也不会自动访问、刷新、同步或更新旧记录。未重新配对的旧记录必须显示为“待重新配对/未信任”，显式 `add-peer` 后才成为可信 API v3 成员。

启用联邦或完成迁移时，如果完整多用户模块没有启用，Shell 使用当前 UUID、订阅 Token、内网/公网订阅端口、Host、HTTP/HTTPS 与证书参数执行 `init-subscription-only`，安装并启动 `lun-agent`，然后停止 BusyBox 订阅及其 cron/OpenRC 遗留。接管前会保存原 config、服务单元、端口文件和 BusyBox 状态；初始化、监听自检或联邦服务任一步失败都会回退，不能留下半启用联邦。停用联邦时仅订阅模式会被移除并恢复 BusyBox；完整多用户模式和独立网站监控保持不变。

服务器编号从 `01` 起永久保存，不重排、不复用。并发编号冲突由签名事件顺序确定。成员地区可在任意可信成员设置，显示为中文。

## 数据边界

- 协议、端口、NAT、证书、Cloudflare Host/Token/Origin Rules/Tunnel 永远只在目标 VPS 本地保存。
- 协议重建成功后，只广播本机签名订阅快照；每个 VPS 使用相同聚合 Token，但输出自己的公开域名/IP 与订阅端口。
- CDN 优选池同步只传递 `cfip/cdnip` 地址。合并为来源优先并追加目标独有地址；覆盖完全替换目标地址池。每个 `trusted=true` 目标分别执行 `cdn-pool-preview`，经逐台确认后执行 `cdn-pool-sync`；各自独立快照、应用、重建与失败回滚。
- `federation-data` 联邦数据备份不含私钥，可在其它成员合并载入，不替换接收方身份。本机完整 `identity` 备份含密码加密私钥，只能本机灾难恢复；`identity-restore` 会拒绝在线身份重复。
