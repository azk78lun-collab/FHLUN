# Lun 服务器联动模块

该目录由 `lun.sh` 的“服务器联动 / 节点集群”菜单管理，不建议手工启动。模块默认未安装，启用后每台服务器运行同一份 `lun_cluster.py`：主 VPS 作为控制器，子 VPS 作为受管节点。

安全边界：

- 一次性 `lunjoin://` 地址有效 15 分钟，首次连接使用 SHA-256 证书指纹锁定。
- 配对后使用集群 CA 签发的 P-256 节点证书及 mTLS。
- 远程只接受结构化白名单动作，不接受任意 Shell 命令。
- 配置、数据库、私钥、快照和备份默认仅 root 可读写。

节点身份：

- 首次建群时主 VPS 为 `01`，子 VPS 顺序分配 `02`、`03`；删除节点后编号不重排、不复用。后续角色互换也不改变物理服务器编号。
- 主 VPS 向子 VPS 下发持久编号和中文地区，并触发本地订阅名称重建。
- 聚合器直接复用各节点的统一名称，不再追加国家代码、主机备注或短 UUID。

角色互换：

- 当前主 VPS 可从菜单选择任一在线且已更新联动程序的子 VPS，将控制面、集群数据库和 CA 私钥迁移过去，再自动降为子 VPS。
- 切换前为其余子机建立 15 分钟双授权窗口；新主机验证全部节点后才提交，失败自动恢复旧主控。
- 服务器编号、地区、UUID、协议端口和节点名称均保持不变；聚合订阅地址改用新主 VPS。
- CA 私钥成功迁移后会从旧主 VPS 的活动控制面删除；两端都保留仅 root 可读的恢复包。

本地测试：

```bash
python3 -m unittest discover -s modules/cluster/tests -v
```

TLS 配对和加密备份用例需要系统安装 OpenSSL。
