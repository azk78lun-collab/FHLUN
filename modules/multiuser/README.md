# FHLUN 可选多用户模块

该目录提供风火轮的可选“多用户管理”模块。未安装模块时，`lun.sh` 的单用户协议、订阅、证书、CDN、NAT 与 Argo 行为保持不变。

## 组件

- `lun_agent.py`：仅依赖 Python 3 标准库，管理 SQLite 用户数据库、配额、配置注入、订阅服务和独立域名访问监控。
- `build-singbox-enhanced.sh`：以相同 Sing-box 版本构建带 `with_v2ray_api` 的增强内核和非驻留统计查询工具。
- `sb_stats_helper.go`：只允许连接回环地址的 Sing-box gRPC 统计查询工具源码。
- `tests/`：数据库、配额、核心配置和订阅渲染单元测试。

服务端口、证书、服务域名、NAT 映射和协议开关仍由 `lun.sh` 管理。模块将当前 UUID 导入为 `legacy-admin / legacy-device`，保留原服务器级传输路径和旧订阅 token。Shadowsocks-2022 优先使用 NAT 映射或端口池中的空闲端口并行迁移，避免改变旧客户端密码格式；没有空闲映射时跳过多用户 Shadowsocks 节点，不阻塞其他协议安装。

启用模块后，设备数据库与 `config.json` 是订阅 token、监听端口和公网端口的权威状态。代理服务启动及菜单刷新时会同步兼容状态文件；“节点订阅分享”直接输出本机设备的有效链接，不再依赖 BusyBox 进程命令行或可能过期的 `subtoken.log`。其他设备的订阅在多用户界面中按设备查看和轮换。

## 本地测试

```bash
python3 -m unittest discover -s modules/multiuser/tests -v
bash -n lun.sh
```

## 安全边界

- 管理操作只通过 root 本地 CLI，不开放公网管理 API。
- 每台设备使用独立 UUID、密码、SS 用户密钥与 32 字节随机订阅 token。
- 订阅目录不可枚举，请求日志不记录 token。
- 网站访问监控默认关闭；启用后数据库、原始日志和备份均按敏感数据处理，仅允许 root 本机管理。
- 默认阻断私网、链路本地、云元数据和 TCP 25；TCP 465/587 不受影响。
- 数据库与配置修改使用 SQLite 事务、原子替换和核心配置校验。
- systemd/OpenRC 之外的无 init 环境拒绝安装常驻模块。

## 动态公平带宽

菜单中的动态公平带宽作用于服务器下载出口。配置值是全机总上限，单位为 Mbit/s。实现优先采用 CAKE 公平队列，内核不支持 CAKE 时回退到 HTB 总量整形和 FQ-CoDel 公平排队。配置通过 systemd/OpenRC 开机恢复；关闭或卸载模块会移除该队列。

## 网站访问监控

监控默认关闭，但不依赖多用户模块处于启用状态。主菜单“一键开启”会建立或复用 `legacy-admin / legacy-device` 内部身份、事务化写入 Xray/Sing-box 日志和身份字段，并安装独立的 `lun-visit-monitor` systemd/OpenRC 服务。该服务不监听网络端口，启动后立即采集一次，之后每 30 秒增量写入共享 SQLite；订阅 HTTP 服务的端口、证书或启动失败不会影响采集，也不依赖第三方 GitHub 项目。

SQLite 逐条记录包含时间、用户、设备、目标域名/端口、内核、传输网络和入站标签；不保存完整 URL、路径、查询参数、请求内容或订阅 token。多用户模式下无法映射到现有设备的身份会被丢弃；单用户且只有一个本机设备时，无身份的 Sing-box 日志可安全归属到该设备。仅有 IP 的目标不会入库。核心原始访问日志可能短暂包含连接源/目标 IP。默认保留 7 天逐条记录和 30 天按日汇总，第 8～30 天只有每日次数统计；逐条记录上限 100,000 条、汇总上限 200,000 条，单个原始日志完成采集后超过 10 MB 会截断。保留期在独立“存储设置”中调整，历史记录需输入 `CLEAR` 才会删除。

Xray 26.3.27 在 `loglevel: none` 时不会创建 access 日志，因此监控启用期间会将该字段按所有权快照提升为 `warning`；停用时仅在字段仍是监控写入值的情况下恢复原设置。

菜单可查看当天最近访问、7 天热门域名、用户访问排行，并可按天数、用户、设备和域名筛选。这里统计的是域名连接次数，不提供每个网站的精确字节用量；用户流量与配额继续使用现有核心统计。加密 DNS、ECH、连接复用和直接访问 IP 会使结果不完整。

## Sing-box 增强内核

普通 Sing-box 仍可承载多用户，但无法提供按用户流量统计。增强构建保持版本不变，只在原有构建标签中增加 `with_v2ray_api`，并配套 `lun-sb-stats` 查询工具。查询工具拒绝非回环 API 地址，不是公网管理接口。构建产物经测试后再作为 Release 资产提供。
