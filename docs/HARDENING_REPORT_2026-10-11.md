# Lun 只读审查问题修复记录

基线：`b429a8f` / `V26.8.10.12`。修复版：`V26.10.11.1`。仅本地实施、验证和提交；未部署 VPS、未推送 GitHub。

## 第一批：订阅、NAT、重试和安全变更

- 订阅 HTTPS 的 TLS 握手移到工作线程；8 秒握手超时、15 秒请求读取超时、最多 64 个连接。保留 IPv4/IPv6 和普通 HTTP。
- Hysteria2 端口跳跃使用 `LUN_HY2_HOP` 专属链和标记；不再清空 `PREROUTING`。规则更新失败恢复旧规则及状态；未标记的旧回源规则保留并提示。
- 集群 `jobs` 增加完整 `result_json`。成功重试返回原结果，失败/执行中/历史结果缺失不伪装成成功；同一请求不重复执行。
- 轮换设备凭据、删除设备和删除用户先保存仅 root 可读的事务快照，验证核心并重启成功，再等待订阅服务启动确认，最后提交和清理旧订阅/自动备份。失败恢复数据库、核心、订阅文件及配置。
- 安全操作期间暂时停止网站采集，避免回滚数据库时覆盖并发采集的数据。提交后清理失败只允许重试清理，不允许重新启用旧凭据。
- 新增内部命令 `security-commit`、`security-rollback` 与 `--defer-security-commit`；普通菜单自动调用，无需用户增加操作步骤。

## 第二批：通信、测速、带宽与代码清理

- mTLS 在发送 HTTP 操作正文之前绑定目标成员身份证书指纹；旧式 CA 模式核对节点证书 CN。身份不匹配、证书无效或 API 拒绝不会切换地址绕过。
- 更新、事件同步、订阅快照广播和健康复核统一使用成员请求入口；IPv4 通信失败后尝试已登记 IPv6，同一操作保持原 request_id。
- 远程结果重放不再次触发服务重启；首次操作即使应答发送失败，也保留必要的服务重启请求。
- CDN 客户端的取消控制器和超时持续到正文下载结束；VPS 使用总截止时间与套接字中断防止正文缓慢滴流。下载计数不超过指定字节量。
- HTTP 80 回退记录真实端口、请求的 HTTPS 端口和 `http` 标记；不混入 HTTPS 延迟中位数，不宣称 HTTPS 或带宽验证成功。
- 带宽队列使用专属 `f1a0:` 根句柄和仅 root 可写的所有权记录。外部自定义队列拒绝覆盖，禁用/卸载只删除可证明属于 Lun 的队列。
- 带宽采用候选配置后提交；规则或服务失败恢复旧配置/队列，切换网卡后只清理旧网卡上的 Lun 队列。旧版未标记队列保留并要求人工核对。
- 安全事务补存核心与订阅服务原状态；原本停止的核心在回滚后仍停止，订阅的自启动状态也恢复。旧模块缺少事务接口时先拒绝修改用户。
- 安全提交之后才清理内部 preinstall 和 previous 备份，避免其中保留被撤销凭据；失败时这些备份继续可供回滚。
- 仅删除被后续定义覆盖的旧 `prompt_port`、`pick_protocols`、`configure_addym_menu`、`lun_menu`。条件模板、旧集群迁移、SAP、容器和镜像脚本保留。
- 版本：多用户 `0.4.1`，集群 `0.2.5`，CDN 优选 `2.0.5`；主脚本同步匹配 CDN 模块版本。
